# JIVAN SETU — Digital Healthcare Portal 🏥

**Jivan Setu** is an open-source, role-based OPD queue and clinic workflow management system designed to tackle real-world Indian outpatient department challenges—such as waiting hall overcrowding, sudden emergency delays, and communication gaps between staff and patients.

### ✨ Key Features
- **Real-Time Queue Tracking:** Live token progression, "Safe to Wait Outside" dynamic buffer, and estimated consultation wait times.
- **Emergency Surgery Sync:** Doctor dashboard toggle that automatically notifies waiting patients and pauses the live queue during acute OT/ICU procedures.
- **Role-Based Access Control:** Dedicated portals for Patients, Clinic Staff (Receptionists), and Doctors with UID credential verification (`DOC-XXXX`).
- **Clinical Triage & Vitals:** Nursing triage recording standard parameters (BP, Pulse, Temp, SpO2, Blood Glucose) with critical flag indicators.
- **Prescription Workflow:** Standardized digital prescription (Rx) compliance and patient record archival.

### 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, Modern JavaScript (ES6+)
- **Storage & State:** Web Storage API (`localStorage`) & Cross-tab Storage Events
